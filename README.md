# サークル（試作）

名前の「サークル」は、使う人が引っかかる角（分かりにくい言葉、読めない文字、届かない知らせ）をできるだけ減らして、丸に近づけていくことを理想にしているからです。

いまいる場所について、公式に出ている防災の情報を集めて並べる試作です。
大雨・土砂災害・高潮・氾濫のレベル３以上が出ていると、その場所の性質（ハザードマップの区域など）とあわせて通知します。
ツキノワグマの出没の記録が地点から 1km 以内・60 日以内にあるときも、通知します（いまは秋田県の公開データの分）。
通知の題は「新宿区 レベル3 氾濫警報」のように、どこで何が出ているかを先に書きます（たたんだ通知で切れない 16 字ほど。絵文字は使いません）。たたんだ 2 行目は題をくり返さず、ひらがなと英語の決まった訳です。
本文は、出どころといつ（気象庁と発表時刻）、気象庁の警報の文の形の案内 1 文（警報は「初台アンダーの冠水に警戒してください」、注意報は「〜に注意してください」。この場所のものを名指しする）、そしてこの場所の公式の事実と出典へのリンクです。逃げる・避難など、どう逃げるかは書きません。

## 審査の方へ（Built with Claude Japan 2026）

テーマ 2「本来、誰にでも届くべきものを。」への応募です。

- **期間中の作り**: このリポジトリのコミットは、すべて期間中（2026-11-03 〜 11-08）のものです。期間前の企画のメモは入れていません。
- **人と Claude Code の分け方**: 何を作るか、何のためか（知らせを受けとった人が危ない所から離れる・近づかない、その一助）、試しで何を見るか、出来の良し悪しは、人（JAWS-Y）が決めました。コード（`app/`・`phone/`・`persona/`）、テスト、この README、作りものの人の試しの組み立てと集計は、Claude Code（Claude Opus 5.5）が書きました。
- **アプリの中の Claude**: 知らせの文を Claude API（`claude-opus-5-5`）が組み立て、アプリが 1 文ずつ確かめて、外れたら事実を並べた文に戻します（下の「Claude で知らせの文を組み立てる」）。
- **作りものの人の試し**: Claude が演じる作りものの人 100 人で、知らせを受けて危ない所から離れられたかを見ました。離れられたのは 48 人です（下の「作りものの人 100 人で、危ない所から離れられたかを見る」）。
- **試し方**: 鍵も携帯も無しで、PC だけで試せます（Python 3 の標準ライブラリだけ）。

  ```
  cd app
  python3 app.py --no-claude
  ```

  http://127.0.0.1:8765/?lat=35.7106&lon=139.8133&demo=flood:4 を開くと、作りものの氾濫警報（レベル 4）を足して知らせを出します。ほかの情報はいまの本物を読みに行くので、ネットにつながっている必要があります。`ANTHROPIC_API_KEY` を置いて `--no-claude` を外すと、Claude が組んだ文に差し替わります。
- **公開のアプリは置いていません**: 悪用と費用を避けるためです。上の手順で、手元で動かしてください。
- **履歴について**: 運営の案内に従い、Git の履歴は書き換えていません。前のコミットのテストにある座標は Claude が試しに作った点で、だれかの居場所ではありません（いまのテストは上の墨田の試しの点です）。
- **動画**: 3 分の説明動画は、提出ページのリンクから見られます。

## 動かし方

Python 3 の標準ライブラリだけで動きます。

```
cd app
python3 app.py
```

ブラウザで http://127.0.0.1:8765/ を開き、「現在地で調べる」を押します。
URL に `?lat=34.47&lon=132.47` を付けると、その地点で調べます。
`python3 app.py --point 34.47,132.47` は、結果を JSON で出します。
テストは `python3 -m unittest test_app test_compose test_phone` です。

### 試し（作りものの警報）

警報が出ていないときでも、知らせと通知を見られます。
画面の「試し」で作りものの警報を 1 つ選ぶと、それを足して調べ直します。ほかの情報はいまの本物です。
URL なら `?lat=35.7106&lon=139.8133&demo=flood:4`、JSON なら `python3 app.py --point 35.7106,139.8133 --demo flood:4` です。
`demo` は `rain`（大雨）・`landslide`（土砂災害）・`flood`（氾濫）・`tide`（高潮）と、`:2`～`:5` のレベルです。
作りものの警報は、名前の後ろに「（試しの作りもの）」、知らせの題の後ろに「（試し）」と付けます（題は「新宿区 レベル3 氾濫警報（試し）」）。本文の試しの印は、1 行目と、ひらがな・英語の行のはじめに 1 か所ずつです。1 行目は、何が作りものかと、どの行が本物かを名指しします（「試し　この警報は作りもの（00:30 作成、気象庁は出していません）。本物は「道路」の行」）。

## 携帯に通知する

携帯のアプリ（`phone/`）が自分の位置を Firebase に書き、PC の `app/phone.py` がそれを読みに行って調べます。
知らせることがあると、PC が Firebase Cloud Messaging の優先度の高い push で携帯に送ります。
携帯を置いたままでも push で起きるので、知らせが遅れません。PC は読みに行くだけで、外からの接続は受けません。
通知の題は「新宿区 レベル3 氾濫警報」の形で、どこで何が出ているかを先に書きます。たたんだ通知は 16 字ほどで切れるので（エミュレータで確かめました）、題は切れない長さにし、絵文字は使いません。たたんだ 2 行目は題をくり返さず、ひらがなと英語の決まった訳です（「かわの はんらん けいほう / Flood」）。レベルは数字の文字で書くので、色だけには頼りません。
本文は、まず出どころといつ（試しなら、何が作りものでどの行が本物かの 1 行）と、案内の 1 文です。次に、警報と案内をひらがなで 1 行、英語で 1 行書きます（警報の名前は気象庁の英語、案内の 1 文はアプリの決まった英訳）。そのあとに、この場所の公式の事実（区域・危険度・雨・道の冠水想定など）とそのよみがな・英語、ボタンにないページの名前です。
通知の文字はリンクにならないので、はじめの 2 つのページ（例: 「警報（気象庁）」「土砂災害の地図」）は通知のボタンで開きます。同じ名前を本文にもう一度は書きません。通知を押すとアプリが開き、最後に届いた知らせ（題・届いた時刻・公式のページの一覧）と、位置を送れているか（送れないときは設定を開く「直す」）が出ます。

位置を読めるのは PC のサービスアカウントだけです（`firestore.rules` で携帯からも誰からも読めません）。
位置は PC の画面にも記録にも出しません。

### 用意（最初の 1 回）

1. Firebase コンソールで新しいプロジェクトを作ります。料金プランは Spark（無料）のままにします。Google アナリティクスは要りません。
2. Android アプリを追加します。パッケージ名は `io.github.jawsy.imakoko` です。`google-services.json` をダウンロードして PC に置きます（このリポジトリには入れません）。
3. Firestore Database を作ります。本番環境モード、場所は `asia-northeast1`（東京）です。「ルール」に `firestore.rules` の中身を貼って公開します。
4. プロジェクトの設定 → サービス アカウント → 新しい秘密鍵を生成します。できた JSON を PC に置き、`chmod 600` にします（このリポジトリには入れません）。
5. PC で携帯を 1 台つなぎます。出てきた 1 行（設定の文）を携帯に送ります。

```
cd app
python3 phone.py pair --google-services ~/firebase/google-services.json --name phone
```

6. 携帯にアプリを入れて開き、「設定」に設定の文を貼って「設定を保存」、「位置を送り始める」を押します。
   通知・位置・位置の「常に許可」を順に聞かれます。

### 試す・動かす


テストは `python3 -m unittest test_phone test_app test_compose` です。

## Claude で知らせの文を組み立てる

知らせの文は、PC で Claude API のキーを設定したときだけ Claude が組み立てます。設定しなければ、公式の事実を並べた文のままです。

```
pip install -U anthropic
export ANTHROPIC_API_KEY=...      # 環境変数だけに置きます。ファイルやこのリポジトリには書きません
python3 app.py
```

- Claude に渡すのは、知らせに入れる公式の事実の文と id だけです。位置・出典・URL は渡しません。
- Claude は事実をつないで読みやすい文にし、文ごとにどの事実を使ったかを返します（JSON の形を決めて受け取ります）。
- アプリが 1 文ずつ確かめます。
  - 事実をすべて使っているか。
  - 事実にない数字・数字の幅・漢数字の数・「」や（）の中の名前が無いか。
  - どう動くか（避難・ください など）、安全・心配ない、予想・おそれ を書いていないか。事実の文にもともとある言葉は使えます。
  - 試しの事実の文は、それだけで最初の 1 文にし、「試し」と書いているか。試しの印はその 1 か所だけです。
- 案内の 1 文（「〜に警戒してください」）は Claude に渡しません。アプリの文のまま、2 文目に入れます。
- 1 つでも外れたら Claude の文は使わず、事実を並べた文に戻します。画面には戻した理由を出します。
- 出典は Claude に書かせず、文ごとに使った事実の出典をアプリが付け直します。
- 同じ事実の知らせには 1 回だけ問い合わせ、返事を覚えておきます。モデルは `claude-opus-5-5` で、混んでいるときは API 側の代わりのモデルに回ります。
- 画面は、まず事実を並べた文を出し、Claude の文が確かめ終わったら差し替えます。携帯の通知はページの名前だけなので、Claude は使いません。
- 使わないときは `app.py --no-claude` か `IMAKOKO_CLAUDE=off` です。モデルは `IMAKOKO_CLAUDE_MODEL` で変えられます。

## 知らせの作り

通知の題・たたんだ 1 行・本文は、警報の文や通知の作りについての調べものにそって作りました。
- 本文の並びは、出どころ → 何の危険 → どこ → いつ → 案内です。この 5 つがそろった警報の文ほど分かりやすい、という研究にそいました（[START/UMD](https://www.start.umd.edu/news/study-shows-longer-emergency-text-alerts-improve-safety)、[Sutton & Kuligowski 2019](https://doi.org/10.1061/(ASCE)NH.1527-6996.0000324)）。研究の 5 つ目は「どう身を守るか」の指示ですが、サークルは決まりでそれを書かず、気象庁の文の形の 1 文（何に気をつけるか）に置きかえています。そのぶん「決める」で止まる人が出ることは見こんでいて、下の作りものの人の試しで、決めるで止まった人を数えています。
- 題は 16 字ほどで、どこで何が出ているかを先に書きます。たたんだ通知で切れないためです（[Android の通知](https://developer.android.com/design/ui/mobile/guides/home-screen/notifications)、緊急速報メールの題も 15 字: [消防庁](https://www.fdma.go.jp/laws/tutatsu/assets/290131_jimurenraku.pdf)）。たたんだ 2 行目は題をくり返しません。
- やさしい日本語の行は短く、同じことを何度も書きません（[やさしい日本語ガイドライン](https://www.moj.go.jp/isa/support/portal/plainjapanese_guideline.html)）。
- 🌊 は使いません。図記号では洪水と津波は別の絵で、絵文字は機種で絵が変わります（[内閣府 図記号](https://www.bousai.go.jp/kyoiku/zukigo/index.html)）。レベルは数字の文字で書きます。
- 試しの印は、本文では 1 行目の 1 か所（ひらがな・英語の行はそのはじめに 1 か所ずつ）にし、本物の行を名指しします。全国一斉の試しでも、受けとった人が戸惑ったり反発したりしています（[The Conversation](https://theconversation.com/nationwide-test-of-wireless-emergency-alert-system-could-test-peoples-patience-or-help-rebuild-public-trust-in-the-system-214453)）。
- 案内の 1 文は気象庁の警報の文の形で、この場所のもの（道の名前など）を名指しします。気象庁の形はレベルで変わります。注意報（レベル 2）は「〜に注意してください」、警報（レベル 3）は「〜に警戒してください」、危険警報（レベル 4）は「〜に厳重に警戒してください」、特別警報（レベル 5）は「〜に最大級の警戒をしてください」です（[気象庁 多言語辞書](https://www.data.jma.go.jp/developer/jma_multilingual.xlsx)）。いまの作りは、レベル 3 から上をすべて「〜に警戒してください」にしています。レベル 4・5 の形に合わせるのは、これからです。

## 作りものの人 100 人で、危ない所から離れられたかを見る

サークルの目的は、知らせを受けとった人が、危ない所から離れる・近づかない、その一助になることです。
試しで見るのは、その目的だけです。離れられた人の数、どこで止まったか、いつ何をしたか。
角を減らすことはサークルの理想で（はじめに書いたとおり）、試しで人に挙げてもらうものではありません。

人は作りもの（実在の人ではない）で、Claude が演じます。年齢・読める文字・目や耳や体の様子・その夜のわけが、一人ずつちがいます。
場面は一つです。11 月の夜 20 時 45 分、新宿区で雨が降っていて、まだ道に水は出ていません。そこへ、レベル 3 の氾濫警報の知らせ（試しの作りもの）が届きます。
いる所はくじで、「いま危ない所」「これから通る」「このあと出かける」のどれかです。

一人に 2 回聞きます。
1. 届いた通知（画面 1）だけを見せて、その人の場面・携帯の設定と、気づくか・どこまで見るかを聞く。
2. その人が見たところまでの画面だけを見せて、知らせから 1 時間を 6 つの段階で聞く。気づく → 分かる → 信じる → 自分のことと思う → 決める → 動く。警報を受けとった人が動くまでを調べた研究の段階です（[Mileti & Sorensen 1990](https://digital.library.unt.edu/ark:/67531/metadc1114590/)、[Mileti & Peek 2000](https://doi.org/10.1016/S0304-3894(00)00179-5)、[Lindell & Perry 2012](https://doi.org/10.1111/j.1539-6924.2011.01647.x)）。どこで止まったか、いつ何をしたか、どうなったか（離れた・避けた・近づかずにいた・とどまった・動けない・近づいてしまった）を答えます。

人は、自分の力の分だけ受けとります。ひらがなまでの人は漢字を読めず、全盲の人は読み上げで上から聞き、ろうの人は通知の音に気づきません。
わざと悪くも、わざとよくもしません。文句を言うためだけの役もありません。

2 回目の後半では、Claude はその人の味方の相談役になります。
人が試すと難しいこと（国や自治体の仕組み、体の不自由に合わせた作り、言葉）も、知っていることをすべて使います。
その人がもっと早く、もっと確かに離れるための案を 1〜5 つと、その人に届く出し方（言葉・文字・読み上げ・音とふるえ・見た目と色・長さ）を出します。

```
cd persona
python3 look.py run --set after3 --round away-after3 -j 4   # 1 人に 2 回 claude -p。道具・MCP・設定は使わない
python3 look.py tally away-after3                           # runs/away-after3/tally.md
python3 look.py ideas --round away-after3                   # 案を似たものごとにまとめる: runs/away-after3/ideas.md・fit.md
```

### 結果（作りものの人 100 人、演じた AI の見立て）

| | 人 |
|---|---|
| **離れられた**（離れた 12・避けた 35・近づかずにいた 1） | **48 / 100** |
| 　うち サークルの知らせで | 44 |
| 　うち ほかのきっかけで | 3 |
| 　うち もともと近づかなかった | 1 |
| 離れられなかった（近づいてしまった 32・とどまった 20・動けない 0） | 52 / 100 |
| 知らせが無かったら離れられた（見立て） | 4 / 100 |

人数だけから見た幅は ±10 ポイントほど（95%）です。

| いる所 | 人 | 離れられた |
|---|---|---|
| いま危ない所 | 34 | 12（35%） |
| これから通る | 33 | 12（36%） |
| このあと出かける | 33 | 24（73%） |

通知に気づいた 98 人のうち 45 人は、たたんだ通知を見ただけでそのままにしました。ひらいたのは 5 人、押してアプリを開いたのは 48 人です。

### どこで止まったか

| 段階 | 通れた | ここで止まった | うち 離れられなかった |
|---|---|---|---|
| 気づく | 98 | 2 | 2 |
| 分かる | 84 | 14 | 12 |
| 信じる | 84 | 0 | 0 |
| 自分のことと思う | 58 | **26** | 25 |
| 決める | 45 | 13 | 13 |
| 動く | 45 | 0 | 0 |
| 止まらなかった | — | 45 | 0 |

- **自分のことと思う（26 人）**: 「新宿区」は広くて自分の所のことか分からない。「レベル 3 ならまだ大丈夫」と思った。名指しした物（0.84km 先の初台アンダー）が遠く、家のそばの川のことだと思わなかった。まだ道に水が出ていない。
- **分かる（14 人）**: ほとんどが漢字を読めない人です。たたんだ通知の「3」「Flood」と赤い印までは分かっても、何が・どこでかが分からず、ひらかなかったので、本文のひらがなと英語の行まで届きませんでした。
- **決める（13 人）**: 避難所の場所を知らない。夜の雨の中を出るほうがこわい。家族に「様子を見て」と言われた。上の階が無い。ほかの道を知らない。

近づいてしまった 32 人のうち 13 人は、危ない所（川沿いの低い道・アンダーパス）を通り過ぎてから、はじめて知らせを読みました。雨の中で音やふるえに気づかなかった、運転中なので見なかった、などです。13 人のうち 12 人は「これから通る」の人です。もう 1 人は最後まで気づきませんでした。
この 13 人は、上の表では「分かる」5・「自分のことと思う」6・「決める」2 で止まったことになっていますが、知らせの中身より先に、気づくのが遅かったことがあります。
残りの 18 人は、通る前に知らせを見ていて、それでも通りました。

### AI は案を全部出し、人が選ぶ

相談役の案は、サークルの決まりとぶつかるものも捨てずに、全部 [ideas.md](persona/runs/away-after3/ideas.md) に並べます。
ぶつかる案には、どの決まりとぶつかるかの印を付けます（1 公式の事実だけ／2 どう動くかを書かない／3 決まった訳・公式の訳だけ／4 位置は PC だけ）。
案は 100 人で 500 件、似たものを AI が 24 のまとめに分けました（まとめは目安で、案はまとめの下に全部あります）。
多かったのは、近くの危ない物を名指しする（64 人）、強い音・ふるえをくり返す（50 人）、ほかの言葉の決まった訳（49 人）、家族などにも同時に届ける（36 人）、公式の川の水位を出す（25 人）です。
「どう動くかを書く」（23 件）はすべて決まり 2 と、「家族などにも同時に届ける」は 37 件のうち 28 件が決まり 4 などとぶつかります。
その人に届く出し方（言葉・文字・読み上げ・音とふるえ・見た目と色・長さ）は [fit.md](persona/runs/away-after3/fit.md) にあります。
AI は一つも落としません。どれをとり、どれをとらないかは人が選びます（human-in-the-loop）。

### 気をつけること

- 作りものの人の答えで、本物の人の声ではありません。LLM が演じた人の答えは、本物の人より答えのばらつきが小さく、属性の人を外から見た型にはめやすいことが分かっています（[Wang ら 2025](https://arxiv.org/abs/2402.01908)、Bisbee ら 2024「Synthetic Replacements for Human Survey Data? The Perils of Large Language Models」Political Analysis）。この割合は避難する人の割合ではなく、同じ人・同じモデル・同じ指示で知らせの版を比べるためのものです。
- 「サークルの知らせで」「知らせが無かったら」は演じた AI の見立てです。AI は、知らせのおかげで動けたと見立てやすいかもしれません。
- 止まった段階は、演じた AI が一人ずつ選びました。通り過ぎてから知らせを読んだ人も「気づく」は通ったことになるので、気づくのが遅い分は表では小さく見えます。
- 場面は 1 つ（新宿区・レベル 3・夜・雨）だけです。同じ写しでも、回ごとに答えは少しゆれます。
- 表とくじごとの数は [persona/runs/away-after3/tally.md](persona/runs/away-after3/tally.md) にあります。
- 前の試し（角を数えた `look-before`〜`look-after3`）は、git の歴史と `persona/runs/` に残っています。
