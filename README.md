# いまいる場所の公式情報（試作）

いまいる場所について、公式に出ている防災の情報を集めて並べる試作です。
大雨・土砂災害・高潮・氾濫のレベル３以上が出ていると、その場所の性質（ハザードマップの区域など）とあわせて通知します。
通知と画面に出すのは公式情報の事実と出典へのリンクだけで、どう動くかは書きません。

## 動かし方

Python 3 の標準ライブラリだけで動きます。

```
cd app
python3 app.py
```

ブラウザで http://127.0.0.1:8765/ を開き、「現在地で調べる」を押します。
URL に `?lat=34.47&lon=132.47` を付けると、その地点で調べます。
`python3 app.py --point 34.47,132.47` は、結果を JSON で出します。
テストは `python3 -m unittest test_app` です。

### 試し（作りものの警報）

警報が出ていないときでも、知らせと通知を見られます。
画面の「試し」で作りものの警報を 1 つ選ぶと、それを足して調べ直します。ほかの情報はいまの本物です。
URL なら `?lat=35.7106&lon=139.8133&demo=flood:4`、JSON なら `python3 app.py --point 35.7106,139.8133 --demo flood:4` です。
`demo` は `rain`（大雨）・`landslide`（土砂災害）・`flood`（氾濫）・`tide`（高潮）と、`:2`～`:5` のレベルです。
作りものの警報は、名前・知らせの題・本文のすべてに「試し」と書きます。

## 読んでいるもの

- 気象庁: 警報・注意報、指定河川洪水予報、キキクル（土砂災害・浸水害）、降水ナウキャスト、アメダス
- ハザードマップポータルサイト: 洪水・内水・高潮・津波の浸水想定区域、土砂災害警戒区域など
- 国土地理院: 自然災害伝承碑

## 出典

- 出典：気象庁ホームページ。キキクルと降水ナウキャストは、地図画像の画素の色を読み取って文字にしています。
- ハザードマップポータルサイト（国土交通省・国土地理院）。データは国土交通省・都道府県・市町村等。地図画像の画素の色を読み取って文字にしています。
- 出典：国土地理院 自然災害伝承碑。
